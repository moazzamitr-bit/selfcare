# Content Governance

محتوای سلامت باید شناسه و نسخه پایدار، منبع، مالک بالینی، reviewer، status، `validFrom`/`validTo`، تاریخ بازبینی و provenance داشته باشد. وضعیت‌ها: draft → scientific review → media review → approved → published → retired.

فقط approved، published و معتبر قابل نمایش/retrieval است. تغییر محتوا نسخه جدید می‌سازد؛ تاریخچه حذف نمی‌شود. emergency content تغییر کنترل‌شده و approval دو نفره می‌خواهد. Foundation هیچ محتوای پزشکی seed نمی‌کند.
