# پرسوناهای پایه

| پرسونا            | نیاز اصلی در Foundation             | محدودیت طراحی                       |
| ----------------- | ----------------------------------- | ----------------------------------- |
| بازدیدکننده عمومی | تشخیص روشن مرز پرتال عمومی          | بدون الزام ورود، زبان ساده          |
| خدمت‌گیرنده       | اطمینان از حریم خصوصی و وضعیت سرویس | RTL، موبایل، اینترنت ضعیف           |
| عضو تیم سلامت     | مرز سازمانی و هویت حرفه‌ای روشن     | MFA و رابطه مراقبتی در آینده اجباری |
| مدیر/بازبین       | قابلیت ردیابی تصمیم‌ها              | دسترسی حداقلی و audit کامل          |
| اپراتور شرکت      | جدایی داده سازمانی از داده سلامت    | tenant boundary و purpose-of-use    |
| ممیز امنیت        | شواهد قابل تکرار از کنترل‌ها        | log بدون PHI/PII و شناسه همبستگی    |

این سند ویژگی جمعیت‌شناختی یا پزشکی حدس نمی‌زند. پژوهش کاربر و نیازهای حقوقی در `assumption-register.md` باز هستند.
