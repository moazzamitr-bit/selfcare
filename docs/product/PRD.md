# سند نیازمندی محصول — Foundation

## هدف

ایجاد پایه مهندسی production-oriented برای سامانه فارسی RTL خودمراقبتی، بدون پیاده‌سازی منطق پزشکی. این مرحله مرزهای پنج سطح محصول، API پایه، زیرساخت توسعه، کنترل‌های ایمنی و مسیر تست را تثبیت می‌کند.

## کاربران و سطوح

- پرتال عمومی: محتوای عمومی و دسترسی پیش از احراز هویت.
- خدمت‌گیرنده: فضای شخصی با مجوز مستقل؛ قابلیت‌های سلامت در این milestone غیرفعال‌اند.
- تیم سلامت: فضای کاری سازمانی با MFA و رابطه مراقبتی در مراحل بعد.
- مدیریت: راهبری، محتوا، سازمان و audit در مراحل بعد.
- ارائه‌دهنده: ثبت و پیگیری خدمات/مدارک در مراحل بعد.

## محدوده این milestone

مونوریپو، پنج shell مستقل، design primitives مشترک، API و AI gateway با health check فاقد قابلیت AI، Docker Compose، CI، observability پایه، اسناد ایمنی/امنیت و smoke test.

## خارج از محدوده

احراز هویت واقعی، داده سلامت، پرسشنامه، امتیازدهی، توصیه پزشکی، RAG، mutation بالینی، FHIR server production و جریان‌های مرحله ۲/۳.

## معیار پذیرش

هر shell در مسیر و پورت مستقل با `lang=fa` و `dir=rtl` render شود؛ health endpointها وضعیت ساختاریافته و بدون داده حساس بدهند؛ lint، type-check، unit/smoke و build در CI قابل اجرا باشند؛ زیرساخت local healthcheck داشته باشد.
