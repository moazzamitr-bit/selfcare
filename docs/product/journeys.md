# سفرهای کاربر — Foundation

## سفر مشترک shell

1. کاربر URL سطح محصول را باز می‌کند.
2. هویت پرتال، عنوان و وضعیت آماده‌سازی را به فارسی می‌بیند.
3. با صفحه‌کلید به «مشاهده وضعیت سامانه» می‌رسد.
4. وضعیت سلامت سرویس بدون نمایش جزئیات داخلی ارائه می‌شود.
5. لینک‌های حریم خصوصی، دسترس‌پذیری و تماس قابل تشخیص‌اند.

## حالت‌های اجباری مراحل بعد

loading، empty، offline، denied و failure باید پیش از فعال‌سازی هر قابلیت محصول طراحی و تست شوند. در Foundation فقط shell و health state وجود دارد؛ هیچ journey بالینی فعال نیست.
